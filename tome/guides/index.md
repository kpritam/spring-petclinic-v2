# Guides

Task-oriented how-to guides for configuring, deploying, and using Spring PetClinic.

- [Configure a database](./configure-database) — switch from H2 to MySQL or PostgreSQL using Spring profiles
- [Run with Docker](./docker) — build a container image and run it with `docker run` or Docker Compose
- [IDE setup](./ide-setup) — import the project into Eclipse, IntelliJ IDEA, or VS Code
- [Change language](./internationalization) — switch the UI language at runtime via URL parameter
